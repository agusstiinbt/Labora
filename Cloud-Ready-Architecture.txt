[HttpPost("book")]
public async Task<IActionResult> Book()
{
    await _queue.PublishAsync(new BookingCreatedEvent());
    return Ok();
}

public class BookingWorker
{
    public async Task Handle(BookingCreatedEvent e)
    {
        await SendEmail();
        await GenerateInvoice();
        await UpdateCalendar();
        await NotifyUser();
    }
}



-----Sobre guardar las imagenes-----

Las imagenes guardarlas en wwwroot es una mala practica en el cloud porque siempre van a haber muchas maquinas
y el disco no es compartido

La solucion debe ser guardarlo en un Storage externo (Blob/S3) o en una base de datos como haciamos en IGift:
En IGift poniamos en la base de datos una tabla con la ruta y las imagenes estaban guardadas en una carpeta fisica
Esto es bueno solamente cuando hacemos pruebas locales pero una vez que subamos a produccion debemos cambiar a un Blob/S3
